# Guía práctica de español para viajeros

Estás en el apartado **3 de 9** del curso: guía práctica en EPUB y PDF.

En este apartado se incluye una guía de apoyo para estudiantes que viajan a España. El material recoge vocabulario y frases útiles para situaciones básicas de viaje.

## Objetivos

- Revisar expresiones frecuentes para viajar por España.
- Consultar vocabulario básico de aeropuerto, alojamiento y restaurante.
- Usar la guía como material de apoyo antes o durante el viaje.


## Materiales disponibles

  [Descargar guía en EPUB](https://ainhoa-bujanda.github.io/mi-curso-guia-espanol/03-guia-viajeros-epub-pdf/espanol_viajeros.epub)


## Cómo abrir el EPUB

El archivo EPUB puede descargarse y abrirse con un lector de libros electrónicos. Algunos navegadores no abren EPUB directamente, por lo que se recomienda usar una aplicación compatible, por ejemplo Calibre, Apple Books, Google Play Books o cualquier lector EPUB instalado en el dispositivo.

## Contenidos

- En el aeropuerto.
- En el alojamiento.
- En el restaurante.
- Frases útiles de supervivencia.

## Accesibilidad

La guía está pensada como material de consulta autónoma. Si el lector EPUB permite aumentar el tamaño de letra, se recomienda ajustar la visualización según las necesidades del estudiante.
