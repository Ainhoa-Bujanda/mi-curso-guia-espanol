# Conversaciones cotidianas en español

Estás en el apartado **2 de 9** del curso: conversaciones cotidianas.

Este apartado presenta expresiones básicas para comunicarse en situaciones frecuentes durante un viaje.

## Objetivos

- Reconocer fórmulas básicas de saludo y cortesía.
- Comprender preguntas frecuentes en contextos cotidianos.
- Practicar respuestas breves y adecuadas.

## Instrucciones para el estudiante

1. Abre la actividad en HTML.
2. Lee las situaciones comunicativas.
3. Practica las expresiones propuestas.
4. Repite las frases en voz alta para mejorar la pronunciación.
5. Vuelve a esta página cuando termines.


## Accesibilidad

La actividad trabaja con frases breves y situaciones comunicativas sencillas. Si alguna parte interactiva no se visualiza correctamente, se recomienda volver a cargar la página o abrirla en otro navegador.
