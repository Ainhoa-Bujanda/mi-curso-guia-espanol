# Cuestionario IMS QTI

Estás en el apartado **5 de 9** del curso: cuestionario IMS QTI.

Este cuestionario permite evaluar la comprensión de expresiones básicas en español de nivel A2.

## Objetivos

- Comprobar la comprensión de vocabulario y estructuras básicas.
- Evaluar la identificación de respuestas adecuadas en situaciones cotidianas.
- Reutilizar el cuestionario en plataformas compatibles con IMS QTI.

## Instrucciones para el estudiante o docente

El archivo se descarga en formato ZIP. Para utilizarlo correctamente, debe importarse en una plataforma compatible con IMS QTI. No es un archivo pensado para abrirse directamente como una página web.


## Material

- [Descargar cuestionario IMS QTI](https://ainhoa-bujanda.github.io/mi-curso-guia-espanol/05-cuestionario-qti/cuestionario_qti.zip)

## Ayuda

Si el archivo no se abre al hacer doble clic, no significa necesariamente que esté mal. El cuestionario debe subirse o importarse en una plataforma que reconozca el formato IMS QTI.
