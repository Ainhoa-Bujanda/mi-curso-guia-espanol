# Narrativa interactiva con RenPy: cortesía en un bar

Esta actividad permite practicar fórmulas de cortesía y peticiones básicas en un bar.

## Objetivos

- Formular peticiones sencillas.
- Usar expresiones de cortesía.
- Elegir respuestas adecuadas en una interacción oral simulada.
