# Guía práctica de español básico para viajeros japoneses en España

![Portada del curso](./assets/img/portada.png)

## Presentación del curso

Este curso está dirigido a viajeros japoneses adultos con nivel inicial de español que desean comunicarse en situaciones básicas durante un viaje a España.

El curso se organiza en diferentes materiales digitales creados con herramientas trabajadas en la asignatura Producción de Materiales Educativos Digitales.

## Objetivo general

Desarrollar la capacidad de los estudiantes para comunicarse de forma básica y autónoma en situaciones cotidianas de viaje: aeropuerto, alojamiento, restaurante y pequeñas interacciones sociales.

## Cómo utilizar el curso

El curso está organizado en nueve apartados. Se recomienda seguirlos en orden, desde la presentación inicial hasta la autoevaluación final, aunque cada material puede consultarse de forma independiente.

Para navegar por el curso, el estudiante puede usar el menú lateral de GitHub Pages/Docsify o los enlaces internos incluidos al final de cada apartado. En cada página aparece también un enlace para volver a la portada.

Algunos materiales se abren directamente en el navegador, como las páginas HTML, la presentación reveal.js, Twine y RenPy. Otros materiales se descargan, como el EPUB, el paquete SCORM, el cuestionario IMS QTI y el PDF de autoevaluación.

## Ayuda para abrir los materiales

- Si un enlace no se abre, se recomienda actualizar la página y comprobar que la conexión a Internet funciona correctamente.
- Si el EPUB no se abre en el navegador, debe descargarse y abrirse con un lector de libros electrónicos, por ejemplo Calibre, Apple Books, Google Play Books o cualquier lector EPUB compatible.
- El paquete SCORM debe importarse en una plataforma compatible, como Moodle o eXeLearning. No está pensado para abrirse directamente como una página web normal.
- El cuestionario IMS QTI debe importarse en una plataforma compatible con este formato.
- Las actividades Twine y RenPy se abren desde el navegador. Si tardan unos segundos en cargar, conviene esperar antes de hacer clic de nuevo.
- ## Accesibilidad y condiciones de uso

El curso se ha diseñado con una estructura clara de encabezados, enlaces descriptivos y materiales organizados por carpetas. Las imágenes principales incluyen texto alternativo y los materiales descargables se acompañan de una breve explicación de uso.

Los materiales del curso tienen una finalidad exclusivamente educativa. Las imágenes, textos y actividades se han creado para este proyecto académico de la asignatura Producción de Materiales Educativos Digitales.
