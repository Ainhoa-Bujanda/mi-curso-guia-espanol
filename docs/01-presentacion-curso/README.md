# Presentación del curso

Estás en el apartado **1 de 9** del curso: presentación general.

Este curso se titula **Guía práctica de español básico para viajeros japoneses en España**.

Está pensado para estudiantes adultos japoneses con nivel inicial de español que necesitan desenvolverse en situaciones reales durante un viaje.

## Destinatarios

Viajeros japoneses adultos con nivel A1/A2 de español.

## Conocimientos previos recomendados

Para seguir el curso, se recomienda conocer el alfabeto latino, algunas fórmulas básicas de saludo y vocabulario muy elemental de español. No es necesario tener experiencia previa con cursos en línea, porque cada apartado incluye instrucciones básicas de uso.

## Duración aproximada

3 horas.

## Contenidos principales

- Llegada al aeropuerto.
- Alojamiento.
- Restaurante.
- Fórmulas de cortesía.
- Peticiones básicas.
- Comprensión de instrucciones sencillas.
