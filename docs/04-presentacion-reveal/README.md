# Presentación interactiva: el imperativo en español

Estás en el apartado **4 de 9** del curso: presentación interactiva con reveal.js.

Esta presentación introduce el uso del imperativo en situaciones comunicativas básicas de viaje.

## Objetivos

- Comprender instrucciones sencillas en español.
- Reconocer formas básicas del imperativo.
- Relacionar el imperativo con contextos reales de viaje.

## Instrucciones para el estudiante

1. Abre la presentación interactiva.
2. Avanza por las diapositivas con las flechas del teclado o con los controles de navegación.
3. Lee los ejemplos con atención.
4. Fíjate en cómo se usan las instrucciones en situaciones de viaje.
5. Vuelve a esta página al terminar.
