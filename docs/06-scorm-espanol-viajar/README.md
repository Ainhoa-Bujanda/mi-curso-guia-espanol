# Actividad SCORM: español para viajar

Estás en el apartado **6 de 9** del curso: actividad SCORM.

Este paquete SCORM contiene una actividad autoformativa sobre español básico para viajar.

## Objetivos

- Practicar vocabulario de viaje.
- Comprender expresiones frecuentes.
- Realizar actividades autocorregibles.

## Instrucciones para el estudiante o docente

El paquete SCORM debe importarse en una plataforma compatible, como Moodle. No está diseñado para abrirse directamente desde el ordenador como una página HTML normal.

Una vez importado en Moodle, el estudiante puede realizar la actividad y, según la configuración de la plataforma, consultar su progreso o puntuación.


## Material

- [Descargar paquete SCORM](https://ainhoa-bujanda.github.io/mi-curso-guia-espanol/06-scorm-espanol-viajar/scorm_espanol_viajar.zip)

## Ayuda

Si el paquete aparece como un archivo comprimido, no lo descomprimas manualmente para usarlo en Moodle. En la plataforma, utiliza la opción de añadir o importar paquete SCORM y sube el archivo ZIP completo.
