# Conversaciones cotidianas en español

Este apartado presenta expresiones básicas para comunicarse en situaciones frecuentes durante un viaje.

## Objetivos

- Reconocer fórmulas básicas de saludo y cortesía.
- Comprender preguntas frecuentes en contextos cotidianos.
- Practicar respuestas breves y adecuadas.
