# Narrativa interactiva con RenPy: cortesía en un bar

Estás en el apartado **8 de 9** del curso: narrativa interactiva con RenPy.

Esta actividad permite practicar fórmulas de cortesía y peticiones básicas en un bar.

## Objetivos

- Formular peticiones sencillas.
- Usar expresiones de cortesía.
- Elegir respuestas adecuadas en una interacción oral simulada.

## Instrucciones para el estudiante

1. Abre la narrativa interactiva RenPy.
2. Espera unos segundos a que cargue la actividad.
3. Lee los diálogos con atención.
4. Elige la respuesta más adecuada para pedir en un bar de forma educada.
5. Si la actividad no carga, actualiza la página o prueba con otro navegador.


## Material

- Juego interactivo para practicar 
- ## Actividad RenPy

## Ayuda

La actividad puede tardar un poco en cargar porque RenPy exporta varios archivos para funcionar en navegador. Si aparece una pantalla en blanco durante unos segundos, espera antes de cerrar la pestaña.

## Accesibilidad

La actividad se apoya en texto, imagen e interacción. Se recomienda leer con calma cada intervención antes de elegir una respuesta. El estudiante controla el ritmo de avance.
